# Youssef Nasser — Portfolio

موقع شخصي بسيط (Static) لـ **يوسف ناصر سعيد الشهالي** — مصمم مواقع ويب ومبرمج ذكاء اصطناعي.

## الملفات
- `index.html` — الصفحة الرئيسية
- `style.css` — التنسيق
- `script.js` — التفاعلات (شاشة الترحيب، الأنيميشن، الخريطة)
- `photo.jpg` — الصورة الشخصية

## رفعه على GitHub Pages
1. اعمل ريبو جديد على GitHub وارفع الملفات الأربعة كلها في الروت (نفس المستوى، من غير فولدرات).
2. من إعدادات الريبو: **Settings → Pages → Source** اختار `main` والفولدر `/ (root)`.
3. هتاخد رابط زي: `https://<username>.github.io/<repo-name>/`
